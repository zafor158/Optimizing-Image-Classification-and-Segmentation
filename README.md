Abstract
Skin diseases present significant challenges in diagnosis due to subjective assessments and limitations in current diagnostic methods. This study explores enhancing the accuracy and efficiency of skin disease classification using both deep learning and machine learning models. Specifically, it investigates custom CNN, ResNet101V2, VGG16, InceptionResNetV2, decision trees, logistic regression, and random forests. YOLOv3 is utilized for image segmentation. Results demonstrate that VGG16 achieves up to 98.48% classification accuracy, while decision trees reach a 99.7% accuracy rate, emphasizing AI's transformative potential in dermatology.

Key Contributions
Objective: Improve the precision of skin disease classification.
Models Evaluated: Custom CNN, ResNet101V2, VGG16, InceptionResNetV2, Decision Trees, Logistic Regression, Random Forests.
Segmentation Technique: YOLOv3.
Results: VGG16 achieves 98.48% accuracy; Decision Tree achieves 99.7% accuracy.
Implications: Paves the way for reliable, real-time diagnostic tools in dermatology.
